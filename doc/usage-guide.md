# YShell 使用帮助

YShell 是一款基于 JavaFX 的跨平台 SSH 客户端，提供终端、SFTP 文件管理、端口转发、Docker、Kubernetes 和 AI 助手等功能。

## 开始前准备

- 使用 SSH、SFTP、Docker 或 Kubernetes 功能前，请确认目标服务器可通过 SSH 访问。
- 使用 Kubernetes 功能时，目标服务器需要安装并配置 `kubectl`，且当前用户具备访问集群的权限。
- 使用 AI 助手前，请先在 AI 助手页面的 **配置** 中添加可用模型连接。

## 建立连接

1. 在左侧服务器列表中创建服务器，或使用 **快捷连接** 临时输入连接地址。
2. 选择连接类型：SSH 或 RDP。
3. 填写主机、端口、用户名和认证信息。
4. SSH 支持密码、私钥和键盘交互认证；RDP 可配置全屏、磁盘映射及弱网络优化。
5. 双击服务器，或在连接编辑窗口中发起连接。

连接成功后，右侧会打开终端和可视区。每个连接拥有独立的终端、可视区标签和面板显示状态。

## 使用终端

- 在终端中直接执行远程命令，窗口尺寸变化会自动同步到远端 PTY。
- 使用终端工具栏可搜索输出、复制粘贴、调整字体、发送中断信号和切换全屏。
- 终端与下方可视区可独立显示或隐藏；重新显示时会恢复该连接之前的分隔位置。
- 可在命令管理中保存常用命令，并对当前连接或多个服务器执行。

## 管理远程文件

在可视区的 **文件** 标签页中可以：

- 浏览远程目录，使用路径导航或刷新操作更新当前目录。
- 上传、下载单个或多个文件，并在传输队列中查看进度与结果。
- 创建、重命名、删除文件和目录。
- 修改文件权限；对目录可选择递归处理。
- 打开文本文件进行在线编辑。
- 创建或解压 tar.gz 压缩包。

执行删除、覆盖或权限修改前，请确认目标路径与操作范围。

## 使用 Docker 管理

切换到 **Docker** 标签页后，YShell 会读取远端 Docker 环境。可用于：

- 查看 Docker 版本以及容器、镜像、网络和存储卷概览。
- 管理容器的启动、停止、重启、暂停、恢复、删除、日志和详情。
- 拉取、加载、导出、标记、推送及清理镜像。
- 创建和管理网络、存储卷与镜像仓库配置。
- 编辑 Docker 配置，并在确认后重启 Docker 服务。

Docker 操作依赖远端用户访问 Docker 守护进程的权限。重启服务、删除容器或清理镜像前，请先确认影响范围。

## 使用 Kubernetes 管理

切换到 **K8s** 标签页后，YShell 会读取集群版本和命名空间。

1. 在左侧选择资源分类与资源类型，例如 Pod、Deployment、Service、ConfigMap 或 Secret。
2. 在右上角选择命名空间；首次加载完成后会默认选中可用列表中的第一个命名空间，也可选择全部命名空间。
3. 使用搜索、分页和刷新定位资源。
4. 选中资源后查看详情或 YAML；根据资源类型执行创建、编辑、删除、扩缩容、重启等操作。

Kubernetes 操作会使用远端 `kubectl` 当前上下文。执行删除、扩缩容、编辑 YAML 或重启前，请确认当前集群和命名空间无误。

## 使用 AI 助手

AI 助手适用于 Linux、Docker 和 Kubernetes 命令咨询与问题排查。

1. 切换到 **AI 助手** 标签页，点击 **配置** 添加模型连接。
2. 选择模型与思考强度，输入问题后发送；支持流式回答和历史会话。
3. 可附加图片以便分析终端截图、报错信息或配置界面。
4. 回答中的命令确认无误后，可发送到当前连接的终端执行。

请勿向 AI 服务发送密码、私钥、访问令牌、生产数据或其他敏感内容。AI 生成的命令应在执行前人工检查。

## 配置端口转发

编辑服务器连接时可添加端口转发规则：

- **本地端口转发**：将远程服务映射到本地端口。
- **远程端口转发**：将本地服务映射到远程端口。
- **SOCKS5 动态转发**：创建本地 SOCKS5 代理。

配置前请确认端口未被占用，并了解目标网络的访问范围。
