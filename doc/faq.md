# YShell 常见问题

## 连接与认证

### 无法建立 SSH 连接

请依次检查：

1. 主机地址、端口和用户名是否正确。
2. 本机能否访问目标主机和 SSH 端口。
3. 目标服务器的 SSH 服务是否已启动，并允许当前用户登录。
4. 是否配置了代理；如已配置，请确认代理地址、端口和认证信息。
5. 服务器是否限制了来源 IP、认证方式或并发会话数。

建议先使用系统命令验证连接，例如：

```bash
ssh user@example.com
```

### 私钥认证失败

- 确认私钥与服务器上 `authorized_keys` 中的公钥匹配。
- 确认私钥文件格式受支持，并正确输入 passphrase。
- 检查远端用户目录、`.ssh` 目录和 `authorized_keys` 文件权限。
- 某些服务器会禁用特定算法或禁止 root 使用密码/私钥登录，请检查 SSH 服务端配置。

### 连接后立即断开

可能原因包括账号 shell 被限制、服务器资源不足、会话超时策略、堡垒机限制或 SSH 服务端日志中存在拒绝记录。请查看服务器的 SSH 日志并确认账号可正常登录。

## 终端

### 终端中文或特殊字符显示异常

确认本地与远端尽量使用 UTF-8 编码。可在远端检查：

```bash
echo "$LANG"
echo "$LC_ALL"
```

如有需要，将环境变量配置为 UTF-8 编码的 locale，例如 `en_US.UTF-8` 或系统可用的 UTF-8 locale。

### 终端看起来被隐藏了

可视区标签栏右侧有终端显示/隐藏按钮。点击后会恢复终端；YShell 会按连接保存终端的显示状态和分隔位置。可视区执行需要终端的命令时，终端也会自动重新显示。

### 终端无法执行命令

确认连接仍处于已连接状态。若终端刚建立连接，请等待 shell 就绪；如命令需要交互式输入、`sudo` 密码或 TTY，请在终端中手动执行并完成交互。

## 文件传输

### 上传或下载失败

- 确认当前用户对目标目录有读取或写入权限。
- 检查本地和远端磁盘剩余空间。
- 检查文件名是否包含远端系统不支持的字符。
- 网络不稳定时，可重新提交失败任务并查看传输队列中的错误信息。

### 文件删除、重命名或修改权限失败

通常是权限不足、文件被占用、路径不存在或目标是只读文件系统。请确认当前用户权限和目标路径，必要时在终端中使用具备相应权限的账号处理。

## Docker

### Docker 页面提示无法读取信息

确认远端已安装并启动 Docker：

```bash
docker version
docker ps
```

如果出现权限错误，请确认当前用户有权访问 Docker 守护进程，例如已加入 `docker` 用户组，或按服务器安全规范使用 `sudo`。

### Docker 操作没有生效

先刷新对应页面并确认当前连接的服务器正确。对于删除、重启、镜像清理和配置修改，请检查 Docker 命令输出或服务日志，以确认是否被权限、策略或依赖关系阻止。

## Kubernetes

### K8s 页面没有命名空间或资源

请在远端终端中检查：

```bash
kubectl version --output=json
kubectl get namespaces
kubectl config current-context
```

确保 `kubectl` 已安装、kubeconfig 可用，并且当前用户拥有目标集群和命名空间的读取权限。

### 资源列表只显示部分资源

检查当前选中的资源类型、命名空间、搜索关键字和页码。选择“全部 namespace”后，部分集群可能因权限限制只返回当前用户可见的命名空间和资源。

### 删除、扩缩容或编辑资源失败

确认当前 kubeconfig 上下文、命名空间和 RBAC 权限。对于生产环境，请先检查 YAML 差异和资源依赖关系，再执行影响服务可用性的操作。

## AI 助手

### 没有可选模型或无法发送消息

打开 AI 助手的 **配置**，确认已添加模型连接，并检查服务地址、模型名称、API Key 和网络代理设置。模型服务不可用或认证失败时，请根据页面错误提示检查服务端配置。

### AI 无法上传或识别图片

图片输入取决于当前模型是否支持视觉能力。请切换到支持图片输入的模型，并确认图片格式和大小符合服务提供方限制。

### AI 生成的命令是否可以直接执行

不建议未经检查直接执行。尤其是涉及删除文件、修改权限、重启服务、Docker 清理、Kubernetes 删除或扩缩容的命令，应先确认目标主机、路径、命名空间和影响范围。

## 更新与反馈

### 检查更新失败

请确认网络能够访问更新服务和项目仓库；如使用代理，请确认代理配置可用。也可以稍后重试，或从项目发布页手动下载更新包。

### 如何提交问题反馈

提交 Issue 时请提供：

- YShell 版本、操作系统和 Java 版本。
- 问题发生前的操作步骤。
- 完整错误提示、相关日志或截图。
- 是否稳定复现，以及对应服务器类型（请勿上传密码、私钥、Token 或敏感业务数据）。
